난방은 **막상 추워진 날 갑자기 문제가 생겨요.** 그때는 수리 예약이 밀려서 며칠을 추위 속에 보내기도 하죠. 쌀쌀해지기 시작한 지금 한 번 점검해 두면 좋아요.

## 먼저: 짧게 시운전

- 난방을 **10~20분 정도 돌려** 보세요
- 방마다 **바닥이 고르게 따뜻해지는지** 확인
- 온수도 함께 확인(수온이 오르는 데 걸리는 시간)
- 작동 중 **이상한 소리나 냄새**가 없는지 살피기

시운전에서 문제가 보이면 지금 부르는 게 나아요. 성수기에는 방문까지 며칠 걸릴 수 있어요.

## 보일러 점검 포인트

| 확인 항목 | 이상 신호 |
| --- | --- |
| 압력계 | 바늘이 정상 범위 아래로 떨어져 있음 |
| 작동음 | 쿵쿵거리거나 끓는 듯한 소리 |
| 배기구 | 막힘, 눌림, 이물질 |
| 누수 | 보일러 아래나 배관 연결부가 젖어 있음 |
| 표시창 | 에러 코드 표시 |
| 냄새 | 가스 냄새(즉시 조치 필요) |

> **가스 냄새가 나면 그 자리에서 밸브를 잠그고 환기한 뒤 전문가에게 연락하세요.** 직접 분해하거나 점화를 반복하지 마세요.

물 보충(보충수)이 필요한 모델은 사용설명서에 절차가 나와 있어요. **압력이 자주 떨어진다면** 어딘가에서 새고 있을 수 있으니 점검을 받는 게 좋아요.

## 배관과 방열

- **배관이 지나는 곳이 찬 공간**이면 보온재 상태를 확인
- 오래된 집은 **동파 방지** 준비(외부 노출 수전, 세탁실 배관)
- 장기간 집을 비울 때는 완전히 끄지 말고 **외출·동결방지 모드** 활용
- 침대·소파가 바닥 난방을 다 덮고 있으면 열이 제대로 퍼지지 않아요

## 전기 난방기기

여름에 넣어 둔 기기를 그대로 꺼내 쓰면 냄새와 먼지가 나요.

- 먼지 제거 후 **처음엔 환기하며** 가동
- 필터가 있는 기기는 세척
- 전선 피복 손상, 플러그 열 변색 확인
- **멀티탭 문어발 금지** — 소비전력이 큰 기기는 단독 콘센트로
- 커튼·침구와 **안전거리 확보**

## 난방비를 줄이는 기본

- **온도보다 일정함** — 껐다 켰다 반복보다 적정 온도 유지가 유리한 경우가 많아요
- 실내 습도를 40~60%로 맞추면 **같은 온도에서 덜 춥게** 느껴져요
- 창문 틈새 바람 막기(문풍지, 틈막이)
- 커튼을 두껍게 하면 창으로 빠지는 열이 줄어요
- 안 쓰는 방은 밸브를 줄이되 **완전히 잠그지는 않기** (결로·동파 위험)

창문 관리는 [창문·방충망 청소](/home/창문-방충망-청소/), 결로로 생기는 곰팡이는 [욕실 곰팡이 제거·예방](/home/욕실-곰팡이-제거-예방/) 글도 참고하세요.

## 한파가 오면: 동파 대비

기온이 영하로 크게 떨어지는 날에는 난방 못지않게 **동파** 가 걱정이에요.

- 집을 비울 때 보일러를 끄지 말고 **외출 모드나 동파 방지 모드** 로 둬요.
- 복도나 외부에 있는 **수도 계량기함** 은 헌 옷이나 보온재로 채워 찬 바람을 막아요.
- 아주 추운 밤에는 욕실이나 주방 수도를 **물방울이 떨어질 정도로 조금** 틀어 두면 배관이 잘 얼지 않아요.
- 배관이 얼었다면 **헤어드라이어나 따뜻한 수건** 으로 천천히 녹여요. 토치나 불을 직접 대면 화재 위험이 있어요.
- 보일러 배관이 얼어 에러가 나면 무리하게 재가동하지 말고 제조사 서비스에 연락해요.

### 가스보일러라면 일산화탄소도 챙겨요

가스보일러는 배기통이 빠지거나 막히면 **일산화탄소** 가 실내로 샐 수 있어요. 냄새가 없어서 알아차리기 어려워요.

- 시운전할 때 **배기통 연결부가 빠지거나 틈이 없는지** 눈으로 확인해요.
- **일산화탄소 경보기** 를 보일러실 근처에 두면 안심이 돼요.
- 두통, 어지럼, 메스꺼움이 여러 사람에게 동시에 생기면 바로 환기하고 밖으로 나가요.

## 점검 체크리스트

- [ ] 난방 10~20분 시운전
- [ ] 방마다 온기 확인
- [ ] 압력계·에러 코드 확인
- [ ] 배기구 막힘 확인
- [ ] 누수 흔적 확인
- [ ] 전기 난방기기 먼지 제거
- [ ] 창문 틈새 점검
- [ ] 필터 청소

난방 준비는 **추워지기 전에 한 번 돌려 보는 것** 이 절반이에요. 압력, 소리, 배기구, 누수만 확인해도 큰 고장을 미리 잡을 수 있어요. 가스나 배기 관련 이상은 직접 손대지 말고 전문가를 부르세요.
