쓰던 폰을 중고로 넘길 때 가장 신경 쓰이는 건 **개인정보** 죠. 초기화 버튼만 누르면 끝날 것 같지만, 순서를 건너뛰면 곤란해지는 경우가 있어요. 백업 방법은 [사진·연락처 백업](/digital/사진-연락처-백업/) 글에 정리해 두었어요.

## 전체 순서 한눈에

| 순서 | 할 일 | 왜 |
| --- | --- | --- |
| 1 | 데이터 백업 | 초기화 후엔 되돌릴 수 없어요 |
| 2 | 각종 앱 로그아웃 | 메신저·금융앱 세션 정리 |
| 3 | 인증서·간편결제 해제 | 기기에 묶인 인증 수단 정리 |
| 4 | 계정 기기 등록 해제 | 잠금 걸림 방지 |
| 5 | 유심·메모리카드 분리 | 물리 저장 매체는 직접 회수 |
| 6 | 공장 초기화 | 마지막에 실행 |

## 1. 먼저 백업부터

- 사진·동영상: 클라우드 또는 PC로 복사
- 연락처: 계정 동기화 확인
- 메신저 대화: 앱 자체 백업 기능 사용
- 인증 앱: 새 기기로 **이전 절차를 먼저** 진행

> 메신저와 인증 앱은 초기화 후 복구가 까다로운 대표 항목이에요. 반드시 새 기기로 옮긴 뒤 초기화하세요.

## 2. 계정과 인증 수단 해제

여기가 가장 많이 놓치는 부분이에요.

- **제조사·OS 계정**에서 기기 등록 해제(분실 방지 잠금 해제)
- 공동인증서·금융인증서 정리
- 간편결제에 등록한 카드 삭제
- 통신사 부가서비스·소액결제 설정 확인
- 워치·이어폰 등 **연결된 기기 페어링 해제**

계정이 묶인 채로 초기화하면 구매자가 폰을 켜도 **이전 계정 확인을 요구하는 잠금**에 걸릴 수 있어요. 나중에 연락 받아 처리하려면 서로 번거로워요.

## 3. 유심과 메모리카드

- **유심(USIM)** 은 반드시 빼서 보관하거나 통신사에 처리
- **SD카드** 는 폰 초기화와 별개예요. 따로 빼거나 포맷
- 케이스 안에 끼워 둔 카드·메모지도 확인

## 4. 공장 초기화

설정 앱에서 초기화 메뉴를 찾아 실행해요. 기기마다 이름이 조금씩 달라요.

- 안드로이드: 설정 → 일반(시스템) → 재설정 → 공장 초기화
- 아이폰: 설정 → 일반 → 전송 또는 iPhone 재설정 → 모든 콘텐츠 및 설정 지우기

초기화 뒤에는 **초기 설정 화면까지 켜서** 계정 잠금이 걸리지 않는지 확인하고 넘기면 깔끔해요.

## 거래할 때 주의할 점

- 직거래는 **사람 많은 공공장소** 에서
- 택배 거래는 배송 전 **기기 상태 사진** 을 남겨 두기
- 결제 전 송금을 유도하거나 링크를 보내는 상대는 조심 — 수법은 [스미싱·피싱 문자 차단](/digital/스미싱-피싱-문자-차단/) 글을 참고하세요
- 분실 신고된 기기인지 확인할 수 있는 조회 서비스도 있어요

## 마무리

중고폰 정리의 핵심은 **초기화가 마지막 단계** 라는 점이에요. 백업하고, 계정과 인증 수단을 풀고, 유심과 메모리카드를 빼낸 뒤에 초기화하세요. 순서만 지키면 개인정보 걱정 없이 깔끔하게 넘길 수 있어요.
