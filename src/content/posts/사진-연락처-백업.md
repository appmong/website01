스마트폰은 언젠가 고장 나거나 잃어버릴 수 있어요. 그때 **사진과 연락처가 한 번에 사라지면** 되돌릴 수 없죠. 자동 백업만 켜 두면 대부분 해결되지만, 해외 IT 매체와 사용자 커뮤니티를 보면 **백업을 켜 놓고도 사진을 잃은** 사례가 꽤 있어요. 대부분 '동기화'와 '백업'을 헷갈려서예요.

> 아이폰은 아이클라우드, 안드로이드는 구글 계정이 기본이에요. 메뉴 이름은 기종마다 조금 달라요.

## 동기화와 백업은 달라요

| 구분 | 동기화 | 백업 |
| --- | --- | --- |
| 뜻 | 폰과 클라우드를 똑같이 맞춤 | 한쪽을 복사해 따로 보관 |
| 폰에서 지우면 | 클라우드에서도 지워짐 | 백업본은 남음 |
| 지켜 주는 것 | 고장·분실 | 고장·분실 + 실수로 지운 것 |

구글 포토, 아이클라우드 사진은 편리하지만 기본적으로 **동기화에 가까워요.** 폰의 사진 앱에서 사진을 지우면 클라우드에서도 지워질 수 있어요. 해외 사용자 포럼에는 "용량 확보하려고 폰에서 사진을 지웠더니 클라우드에서도 사라졌다"는 경험담이 반복해서 올라와요.

**용량을 비울 땐 사진을 직접 지우지 말고**, 앱이 제공하는 기능을 쓰세요.

- 구글 포토: **기기 저장공간 확보** — 백업이 끝난 사진만 폰에서 지우고 클라우드엔 남겨요
- 아이폰: **iPhone 저장 공간 최적화** — 폰에는 작은 사본만 두고 원본은 아이클라우드에 둬요

지워진 사진은 휴지통에 30일 정도 머무니, 실수했다면 바로 휴지통부터 확인하세요.

## 사진 자동 백업 켜기

- [ ] 구글 포토 또는 아이클라우드 사진 **자동 백업 켜기**
- [ ] **와이파이에서만** 업로드하도록 설정(데이터 절약)
- [ ] 백업 화질 확인 — 원본은 용량을 더 써요
- [ ] 처음 한 번은 **업로드 완료 표시** 를 직접 확인하기
- [ ] 메신저·SNS 앱 폴더도 백업 대상에 넣을지 선택

## 소중한 사진은 두 곳 이상에

사진 작가들이 쓰는 **3-2-1 원칙** 이 있어요. 파일을 **3개** 사본으로, **2가지** 다른 저장 매체에, 그중 **1개** 는 집 밖(클라우드 등)에 두는 거예요. 일반 사용자라면 이 정도로 줄여도 충분해요.

- **클라우드 자동 백업** (폰 고장·분실 대비)
- **1년에 한두 번 PC나 외장하드로 복사** (실수로 지운 것·계정 문제 대비)

아이 사진, 가족 행사 사진처럼 다시 찍을 수 없는 사진은 특히 두 곳에 두는 걸 권해요.

## 연락처 백업

연락처는 **어디에 저장하느냐** 가 핵심이에요.

- 연락처를 저장할 때 **'휴대전화'가 아니라 계정(구글·애플)** 을 선택해요.
- 기존 연락처가 폰에만 저장돼 있다면, 연락처 앱의 설정에서 **계정으로 옮기기(이동)** 기능을 써요.
- 설정 → 계정 → 연락처 동기화가 켜져 있는지 확인해요.
- 유심에 저장된 옛 연락처도 계정으로 옮겨 두면 안전해요.

## 메신저 대화 백업

메신저 대화는 사진·연락처와 별도로 **앱 안에서 따로** 백업해야 해요.

- 앱 설정의 **대화 백업** 메뉴에서 백업하고, 백업 비밀번호를 꼭 기억해요.
- 새 폰에서 같은 계정으로 로그인한 뒤 **복원** 해요.
- 백업에는 기간 제한이 있는 경우가 있으니, 폰 교체 직전에 하는 게 좋아요.
- 사진·동영상 파일까지 옮겨지는지는 앱마다 달라요.

## 폰 바꿀 때 순서

1. 옛 폰: 사진 백업 완료, 연락처 동기화 확인
2. 옛 폰: 메신저 대화 백업
3. 옛 폰: 인증서·인증 앱 이전 절차 진행
4. 새 폰: 같은 계정으로 로그인 → 사진·연락처 확인 → 메신저 복원
5. 모두 확인한 뒤에 옛 폰 초기화 → [중고폰 초기화](/digital/중고폰-판매전-초기화-개인정보/)

## 분실·도난 대비

- **'내 기기 찾기'** (구글·애플)를 켜 두면 위치 확인, 원격 잠금, 원격 초기화가 가능해요.
- 잠금 화면 비밀번호와 생체 인증은 꼭 설정해요.
- 분실했다면 통신사에 **분실 신고** 를 하고, 금융 앱 비밀번호를 바꿔요.

## 자주 묻는 것

**클라우드 무료 용량이 부족해요.**
중복·흐린 사진과 오래된 동영상부터 정리하면 꽤 줄어요. 저장공간 확보 방법은 [저장공간 부족할 때](/digital/스마트폰-저장공간-확보/)에 정리해 두었어요.

**아이폰에서 갤럭시로 바꾸면요?**
구글 포토를 아이폰에도 설치해 백업해 두면 기종이 달라도 그대로 옮겨져요. 제조사가 제공하는 기기 전환 앱도 있어요.

백업은 **자동 백업 켜기, 연락처는 계정에, 메신저는 따로, 소중한 사진은 두 곳에** 이 네 가지면 충분해요.
