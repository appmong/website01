스마트폰에는 **있는 줄 몰라서 못 쓰는 기본 기능** 이 꽤 많아요. 해외 IT 매체의 '몰랐던 기능' 기사에 매번 빠지지 않고 나오는 것들을 골랐어요. 몇 개만 알아 둬도 매일 조금씩 편해져요.

> 기종·운영체제 버전에 따라 이름과 위치가 조금씩 달라요. 못 찾겠다면 **설정 맨 위 검색창** 에 기능 이름을 입력해 보세요.

## 1. 텍스트 대치 — 자주 쓰는 긴 문구를 짧게

이메일 주소, 집 주소, 계좌번호처럼 자주 치는 긴 문구를 **짧은 단어로 등록** 해 두는 기능이에요.

- 아이폰: 설정 → 일반 → 키보드 → 텍스트 대치
- 갤럭시(삼성 키보드): 키보드 설정 → 추가 입력 옵션 → 텍스트 바로가기
- 예: "ㅁㅇ"을 입력하면 이메일 주소가 추천으로 떠요

비밀번호나 주민번호처럼 민감한 정보는 등록하지 마세요.

## 2. 사진 속 글자 복사하기

사진이나 캡처 화면 속 글자를 **바로 복사** 할 수 있어요. 명함, 안내문, 와이파이 비밀번호 스티커를 옮겨 적을 필요가 없어요.

- 아이폰: 사진을 열고 글자를 길게 누르거나 오른쪽 아래 글자 인식 버튼
- 갤럭시: 사진을 열고 'T' 모양 글자 추출 버튼, 또는 카메라 화면에서 인식
- 전화번호나 주소는 누르면 바로 전화·지도로 연결돼요

## 3. 화면 녹화

캡처(사진)뿐 아니라 화면을 **동영상** 으로 저장할 수 있어요.

- 제어 센터(아이폰)나 빠른 설정(갤럭시)에 '화면 녹화'를 추가해 두면 한 번에 켜요
- 부모님께 앱 쓰는 법을 알려 드리거나, 오류 상황을 고객센터에 보낼 때 유용해요
- 소리가 필요하면 시작 전에 마이크·내부 소리 옵션을 확인해요

## 4. 길게 캡처(스크롤 캡처)

웹페이지나 긴 대화를 **한 장으로** 담을 수 있어요.

- 아이폰: 사파리 등에서 캡처 후 미리보기 → '전체 페이지'
- 갤럭시: 캡처 직후 아래 도구 막대의 스크롤 캡처 버튼

## 5. 뒷면 두드리기·측면 버튼 단축키

- 아이폰: 설정 → 손쉬운 사용 → 터치 → **뒷면 탭** 에서 두 번·세 번 두드릴 때 캡처, 손전등, 카메라 등을 지정할 수 있어요.
- 갤럭시: 측면 버튼 설정에서 **두 번 누르기** 로 카메라나 원하는 앱을 바로 열 수 있어요.

## 6. 한 손 모드

큰 화면을 한 손으로 쓸 때 화면 전체를 아래로 내려 줘요.

- 아이폰: 손쉬운 사용 → 터치 → **간편 접근** 을 켜고 화면 아래를 아래로 쓸어내려요
- 갤럭시: 설정 → 유용한 기능 → **한 손 조작 모드**

## 7. 소소하지만 편한 것들

| 기능 | 쓸모 |
| --- | --- |
| 손전등 밝기 조절 | 손전등 아이콘을 길게 눌러 밝기 단계 조절 |
| 돋보기 | 작은 글씨·약 설명서를 카메라로 크게 |
| 빠른 설정 편집 | 자주 쓰는 기능을 앞으로 배치 |
| 방해 금지·수면 모드 | 밤에 알림 차단, 특정 사람 전화만 허용 |
| 키보드 커서 이동 | 스페이스바를 길게 누르고 좌우로 움직이면 커서 이동 |
| 흔들어서 실행 취소 | 아이폰에서 글을 잘못 지웠을 때 흔들면 되돌리기 |

## 8. 접근성 메뉴는 모두에게 유용해요

'접근성'이나 '손쉬운 사용' 메뉴는 장애가 있는 사용자를 위해 만들어졌지만, 누구에게나 편한 기능이 많아요.

- **글자 크기·굵기** 키우기
- **화면 색 필터** 로 눈부심 줄이기
- **소리 인식** 으로 초인종, 아기 울음 알림 받기
- 특정 앱만 쓸 수 있게 화면을 고정하기(아이에게 폰을 잠깐 줄 때)

## 자주 묻는 것

**제 폰엔 그 메뉴가 안 보여요.**
기종과 운영체제 버전에 따라 이름이 달라요. 설정 맨 위 검색창에 '텍스트 대치', '화면 녹화'처럼 기능 이름을 쳐 보세요.

**화면 녹화에 소리가 안 들어가요.**
녹화 설정에서 마이크나 내부 소리 옵션을 켜야 해요. 일부 앱(OTT 등)은 저작권 보호 때문에 녹화가 막혀 있어요.

**배터리를 많이 쓰진 않나요?**
여기 소개한 기능들은 쓸 때만 동작해서 배터리에 큰 영향은 없어요. 배터리 관리는 [배터리 수명 관리](/digital/배터리-수명-관리/)에 정리해 두었어요.

오늘 딱 하나만 해 본다면 **텍스트 대치에 이메일 주소 등록하기** 를 추천해요. 매일 몇 초씩 아껴 주는 기능이에요.
