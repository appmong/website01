"택배 주소 오류", "부고 알림", "환급금 조회", "모바일 청첩장" 같은 문자에 링크가 달려 오면 무심코 누르기 쉬워요. 이런 **스미싱(문자 사기)** 은 링크 한 번, 앱 설치 한 번으로 연락처와 금융 정보가 빠져나가고, 심하면 내 명의로 대출이나 휴대폰 개통까지 이어져요. 수법은 계속 바뀌지만 **구별하는 원칙은 거의 같아요.**

## 요즘 자주 오는 유형

| 유형 | 예시 문구 |
| --- | --- |
| 택배 사칭 | 주소 불일치로 반송 예정, 주소 확인 요망 |
| 경조사 사칭 | 부고 안내, 모바일 청첩장 |
| 기관 사칭 | 건강검진 결과, 과태료·범칙금 조회, 세금 환급 |
| 지인 사칭 | 폰이 고장 나서 이 번호로 연락해, 급하게 돈 좀 |
| QR코드(큐싱) | 주차 위반 딱지·전단지에 붙은 QR코드 |

**큐싱** 은 문자 대신 QR코드를 이용하는 방식이에요. 주차된 차에 붙은 딱지나 공공장소 전단의 QR코드를 찍으면 가짜 사이트로 연결돼요. 서울시도 큐싱 주의 안내를 따로 낼 만큼 늘고 있어요.

## 의심 신호

- **재촉**: "오늘까지", "지금 확인하지 않으면 불이익"
- **링크·앱 설치 요구**: 문자 속 링크를 누르거나 앱(APK)을 깔라고 함
- **정보·돈 요구**: 주민번호, 계좌, 인증번호, 카드 비밀번호를 물어봄
- **이상한 주소**: 공식 주소와 비슷하지만 철자가 다르거나 단축 URL
- **국제전화·모르는 번호**, 어색한 맞춤법

> 공공기관과 택배사는 문자로 **개인정보, 인증번호, 앱 설치를 요구하지 않아요.**

## 평소에 해 둘 안전 수칙

- [ ] 모르는 링크는 누르지 않기. 택배·기관은 **공식 앱이나 직접 검색한 누리집** 으로 확인
- [ ] 문자로 온 **앱 설치 파일(APK)은 절대 설치하지 않기**
- [ ] 안드로이드는 설정에서 **출처를 알 수 없는 앱 설치를 막아 두기**
- [ ] 통신사 스팸 차단·필터링 서비스 켜기
- [ ] 부모님 폰에도 같은 설정 해 드리기
- [ ] **엠세이퍼** 에서 내 명의로 개통된 휴대폰 조회, 신규 개통 제한 신청

엠세이퍼는 한국정보통신진흥협회가 운영하는 무료 서비스로, 내 명의로 몰래 휴대폰이 개통되는 걸 막는 데 도움이 돼요.

## 눌렀거나 앱을 깔았다면, 이 순서로

**링크만 눌렀고 아무것도 설치·입력하지 않았다면**
대개 큰 문제는 없어요. 창을 닫고, 이후 뜨는 설치나 입력 요구를 절대 따르지 마세요.

**앱을 설치했거나 정보를 입력했다면**
1. **비행기 모드** 로 바꿔 데이터를 끊어요. 악성 앱이 정보를 보내지 못하게요.
2. 다른 사람 폰이나 PC로 **거래 은행에 전화해 지급정지** 를 요청해요. 시간이 가장 중요해요.
3. 설치된 **의심 앱을 삭제** 해요. 삭제가 안 되면 서비스센터에서 초기화를 해요. 경찰청 악성 앱 탐지 앱(시티즌코난)으로 확인하는 방법도 있어요.
4. 주요 계정(메일, 포털, 메신저) **비밀번호를 바꿔요.**
5. 신분증 사진 등을 보냈다면 금융감독원 **개인정보 노출자 등록** 을 해서 추가 대출·계좌 개설을 막아요.
6. 경찰(112)에 신고하고, 피해 사실을 기록해 둬요.
7. 내 연락처로 같은 문자가 퍼졌을 수 있으니 주변에 알려요.

## 신고·상담처

| 상황 | 연락처 |
| --- | --- |
| 스미싱 문자 신고·상담 | 118 (한국인터넷진흥원) |
| 금전 피해, 사기 신고 | 112 (경찰), 거래 금융기관 |
| 금융 피해 상담, 개인정보 노출 등록 | 1332 (금융감독원) |

## 자주 묻는 것

**가족 번호로 돈을 보내 달라는 메시지가 왔어요.**
계정 도용이나 번호 바꿔치기일 수 있어요. 문자·메신저로 답하지 말고 **원래 알고 있던 번호로 직접 전화** 해서 확인하세요.

**진짜 택배 문자인지 모르겠어요.**
문자 속 링크 대신 택배사 공식 앱이나 쇼핑몰 주문 내역에서 송장 번호로 조회하세요.

**QR코드는 어떻게 조심해요?**
찍은 뒤 열리는 **주소를 먼저 확인** 하고, 로그인이나 결제를 요구하면 멈추세요. 공공장소에 덧붙인 스티커 QR은 특히 의심하세요.

폰을 팔거나 바꿀 때 개인정보를 지우는 법은 [중고폰 초기화](/digital/중고폰-판매전-초기화-개인정보/)에 정리해 두었어요. 스미싱은 **누르지 않고, 설치하지 않고, 공식 경로로 확인하기** 세 가지면 대부분 막을 수 있어요.
